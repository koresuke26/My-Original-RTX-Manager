# My Original RTX Manager

Minecraft Bedrock Edition の RTX / PBR / Vibrant Visuals 環境を管理・診断・調整する Windows 向けツールです。

リソースパックの状態確認、PBR設定の管理、GPUに応じた推奨値、プリセット、バックアップ、診断などをまとめて行えます。

## 主な特徴

### Multi Render Core
共通PBR情報を基準に、RTX と Vibrant Visuals へそれぞれ最適化した処理を行う独自マルチ描画技術です。

### External Pack Rebuild
専用パックだけでなく、ユーザーが所有する外部 RTX / PBR リソースパックを解析・調整・再構成できます。

### Lightweight Architecture
主要機能を維持しながら、Python版を約300KB級に抑えた軽量構造を採用しています。

### Safe Processing Architecture
元データを直接破壊的に編集せず、作業用コピー、バックアップ、履歴、診断を組み合わせて処理します。

## 主な機能

- PBR / RTX リソースパック管理
- RTX / VV / RTX+VV / LITE 向け生成・調整
- 外部PBRパック解析
- GPUに応じた推奨設定
- PBR診断
- プリセット管理
- バックアップ・復旧
- 生成履歴管理
- 多言語対応
